# Procedimento de Inicialização de Projeto

Ao iniciar um novo projeto utilizando este template base:

1. Escolha o esqueleto adequado na pasta `templates/` (`web-nextjs`, `edge-cloudflare-worker`, ou `mobile-flutter`).
2. Copie a estrutura do template para o repositório de destino.
3. Copie a pasta `.agents/` e o arquivo `GEMINI.md` para a raiz do novo projeto.
4. Execute a instalação de dependências e verifique se as variáveis de ambiente `.env.example` foram configuradas como `.env`.
